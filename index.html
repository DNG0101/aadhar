      How This Scanner Works (Deep Logic)
    


    

      
1

      

        Camera Access via MediaDevices API

        Requests rear camera (facingMode: "environment"), streams to <video> element.
        Android equivalent: Google Mobile Vision BarcodeCapture fragment.
      

    


    

      
2

      

        QR Detection — ZXing Decoder (Reed-Solomon)

        Frames are sampled and decoded using ZXing (Zebra Crossing) library.
        QR codes use Reed-Solomon error correction to recover data even if up to 15% (Level M) of the QR is damaged.
        ZXing identifies finder patterns (3 corner squares), timing patterns, and alignment patterns to locate and decode the QR matrix.
      

    


    

      
3

      

        XML Parsing — The Core Logic

        Aadhaar QR raw value is XML (not plain text). The app checks:
        (a) Root element = PrintLetterBarcodeData
        (b) Attribute uid exists → valid Aadhaar QR.
        Uses DOMParser (text/xml) then getAttribute(). Android used org.json.XML.toJSONObject().
      

    


    

      
4

      

        17-Field Data Extraction (UidModel)

        Extracts: uid, name, gender, yob, dob, co, house, street, lm, loc, vtc, po, dist, subdist, state, pc, country.
        Gender codes: M=Male, F=Female, T=Transgender.
      

    


    

      
5

      

        Result Display & Masked UID

        Aadhaar number is partially masked (first 8 digits shown as ✱✱✱✱ ✱✱✱✱ for privacy, last 4 visible). All address fields displayed in structured layout.
