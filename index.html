⚙️ How This Scanner Works (Deep Logic)


    
1

      
Camera via MediaDevices API

        Requests rear camera (facingMode:"environment"), streams to <video>. Frames drawn to <canvas> for processing. Android used Google Mobile Vision BarcodeCapture fragment.

    


    
2

      
QR Decoding — jsQR (Reed-Solomon Algorithm)

        Each canvas frame is passed as ImageData to jsQR(data, width, height).
        jsQR finds the 3 finder patterns, reads timing/alignment grids, applies Reed-Solomon ECC (Level M = 15% error recovery), and decodes the raw byte string.

    


    
3

      
XML Parsing — The Core Aadhaar Logic

        The QR raw value is XML. Parsed with DOMParser("text/xml").
        Validates: (1) root element = PrintLetterBarcodeData, (2) attribute uid exists.
        Android used org.json.XML.toJSONObject(rawValue) + JSONObject.has().

    


    
4

      
17-Field Extraction (UidModel)

        All fields read via getAttribute(): uid, name, gender, yob, dob, co, house, street, lm, loc, vtc, po, dist, subdist, state, pc, country.
        Gender: M=Male, F=Female, T=Transgender.

    


    
5

      
Display & Privacy

        Aadhaar number masked as ✱✱✱✱ ✱✱✱✱ XXXX (last 4 visible). All 17 address/personal fields shown in structured card. Raw XML viewable for debugging.
