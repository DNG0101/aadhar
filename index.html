⚙️ Aadhaar QR Formats & Algorithm


    
A

      
Old XML Format (pre-2019)

        QR stores raw XML. DOMParser("text/xml") → find
        PrintLetterBarcodeData root → extract 17 attributes.
        Validation: root element exists AND uid attribute present.

    


    
B

      
New Secure QR — Numeric Mode (most modern cards)

        QR uses NUMERIC encoding → stores a very long decimal number (100+ digits).
        jsQR gives this as a digit string in code.data.
        Convert: BigInt(str) → big-endian byte array → split by 0xFF byte.
        Fields (0xFF-delimited): seg[0]=header, seg[1]=Name, seg[2]=DOB, seg[3]=Gender,
        seg[4]=CareOf, seg[5]=District, seg[6]=Landmark, seg[7]=House, seg[8]=Locality,
        seg[9]=PIN, seg[10]=PostOffice, seg[11]=State, seg[12]=Street,
        seg[13]=SubDist, seg[14]=VTC.

    


    
C

      
New Secure QR — Byte Mode

        QR uses BYTE encoding → code.binaryData contains actual raw bytes.
        Same 0xFF-split algorithm as Format B applied directly to binaryData.

    


    
D

      
Upload Image Support

        Image drawn to <canvas> → jsQR(imageData) decodes QR →
        same parsing pipeline. Works with photos of Aadhaar card or screenshots.
