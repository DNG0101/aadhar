⚙️ Official UIDAI Secure QR Algorithm


    
1

      
QR scan → decimal string

        jsQR reads the NUMERIC-mode QR → gives you a 500–700 digit decimal number string.

    

    
2

      
BigInt → byte array

        BigInt(str) → extract big-endian bytes with right-shift loop until 0.

    

    
3

      
ZLIB decompress ← the key missing step

        Raw bytes are zlib-compressed. pako.inflate(bytes) decompresses them.
        Without this step you get garbage like "pEy", "PW0554ZRS".

    

    
4

      
Split by byte value 255 (0xFF) → ISO-8859-1 strings

        Fields: [0] email/mobile indicator → [1] refId →
        [2] name → [3] DOB → [4] gender →
        [5] careOf → [6] district → [7] landmark →
        [8] house → [9] location → [10] pincode →
        [11] postOffice → [12] state → [13] street →
        [14] subDistrict → [15] VTC

    

    
5

      
Photo + hashes + signature (from end)

        After VTC: JPEG2000 photo (variable). From end: 256B RSA signature +
        32B mobile hash + 32B email hash (per indicator). Photo displayed inline.
