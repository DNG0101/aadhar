💡 Tips for best results

    
1
Camera uses native BarcodeDetector API on Android Chrome / Samsung Browser / Safari iOS 17+ — hardware-accelerated, decodes Aadhaar QR in under 200ms. Falls back to jsQR if unavailable.

    
2
Upload uses QrScanner (ZXing TRY_HARDER) as primary — handles 177×177 Version-40 dense QR in a single pass without multi-scale loops

    
3
Photo — stored as JPEG2000 (JP2) inside the QR. Decoded via embedded PDF engine. Click photo to enlarge

    
4
Mobile verification — SHA-256 applied N times (N = last digit of Aadhaar UID per UIDAI spec). Tries iterations 1–9 exhaustively. Verified number shown on card.
